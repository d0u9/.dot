This directory contains optional host-specific Zsh hooks. `pre.zsh` sources
every readable regular file or symlink ending in `-pre.sh` or `-pre.zsh`;
`post.zsh` does the same for `-post.sh` and `-post.zsh`.

All contents except this note are ignored by the public repository. The prefix
is not an enablement condition; use it only to describe hooks and control their lexical
load order. Files without one of the four recognized suffixes are not sourced.

This note is public and also keeps the directory in Git. Never put private
configuration, credentials, or real host details in it.

To override the host displayed in the SSH prompt, set DOT_PROMPT_HOST in a pre
hook, as in Bash:

    echo 'DOT_PROMPT_HOST=host-a' > 10-host-pre.sh

Zsh also accepts the older HOSTALIAS variable when DOT_PROMPT_HOST is empty.
